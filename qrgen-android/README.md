# Avtobys — Android демо-макет

Макет интерфейса оплаты проезда (Kotlin + Jetpack Compose). Сервера нет:
оплата и выдача билета эмулируются заглушкой `FakePaymentRepository`.

* Билет и экран везде помечены как **ДЕМО** и не действительны для проезда.
* QR содержит токен вида `DEMO-TICKET:<id>:<exp>`.
* Для подключения бэкенда реализуйте `PaymentRepository` (файл `Payment.kt`):
  сервер принимает оплату и возвращает подписанный токен, приложение лишь рисует его в QR.
  Проверка подписи и срока действия — на стороне приложения контролёра/сервера.

## Сборка
* Android Studio: открыть папку проекта → Run.
* GitHub Actions: push в `main` → артефакт `QRGen-demo-apk` (app-debug.apk).
* Локально с установленным Gradle 8.7+ и JDK 17: `gradle assembleDebug`.
